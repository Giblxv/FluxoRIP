## 3. Manifest read hardening

`verified_ternary.py` now reads manifests through a size-bounded OS file descriptor and checks file metadata before and after the read. It rejects nonregular files, changed paths, malformed manifests, unexpected labels and invalid SHA-256 notation before starting the expensive ternary scan.

These checks reduce, but cannot mathematically eliminate, concurrent replacement risks on all filesystems.

## 4. Scientific scope and exclusions

These are three **operator-labelled** variations, not confirmed byte-level Spot_1 fields. Structural hypotheses such as 12 candidate regions, bit-packing, ICC semantics and mapping to white ink remain unproven. The PRT files were generated by FlexiPRINT; PrintExp is the Hoson controller software. No printer commands, print-ready PRT files, ICC profiles or proprietary binary bytes were generated or uploaded to GitHub. The `main` branch was not changed.
