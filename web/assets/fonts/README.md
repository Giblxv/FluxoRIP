# Fontes locais do Studio DTF

Archivo (pesos 600–900) e Public Sans (400–700), subconjuntos Latin e Latin Extended, em WOFF2 variável. Distribuídas com a SIL Open Font License 1.1; textos de licença preservados nos arquivos `Archivo-OFL.txt` e `PublicSans-OFL.txt`.

Obtidas em 7/11/2026 pelo endpoint oficial Google Fonts (`fonts.googleapis.com`, arquivos de `fonts.gstatic.com`). As licenças vêm de `google/fonts`, pastas `ofl/archivo` e `ofl/publicsans`. O Studio carrega esses arquivos locais e usa fontes do sistema como fallback para outros alfabetos; não depende de acesso ao Google Fonts na operação.
