# Fluxo RIP 1.5.1 — arquivos de entrega

- **FluxoRIP-1.5.1-Instalador-Windows-x64.exe:** instalador por usuário para Windows x64.
- **FluxoRIP-GitHub-Pages-1.5.1.zip:** página de download, instalador e workflow prontos para GitHub Pages; extraia e siga o README do pacote.
- **SHA256SUMS.txt:** hashes dos dois arquivos para conferência.

Esta branch é uma entrega de artefatos. Ela preserva a main e não publica a landing page automaticamente.
A versão 1.5.1 usa motion cartoon completo por padrão, com pausa manual persistente.

O instalador foi compilado e testado sob Wine no Linux. A validação nativa no Windows 10 22H2/11 x64, WebView2, Windows Forms e ACL NTFS continua pendente; o pacote não possui assinatura digital.
Antes de atualizar, feche o aplicativo e os agentes e faça backup de %LOCALAPPDATA%\FORGE.

A fila é administrativa: não aciona impressão, limpeza, calibração nem aplicação de firmware/ICC à controladora Hoson.
Nenhum banco, credencial ou arquivo de cliente acompanha esta entrega.
