# COMECE_AQUI_CODEX.md

O projeto chama-se **Fluxo RIP** (antigo FORGE). Você recebeu o código-fonte v1.4 e o histórico de requisitos consolidado.

## Como continuar no aplicativo Codex do Windows
1. Extraia este ZIP em uma pasta, por exemplo `C:\Projetos\FluxoRIP`.
2. Abra o aplicativo ChatGPT para desktop, selecione **Codex** e crie/abra um projeto local apontando para a pasta extraída. Ou use Codex CLI/IDE a partir dessa pasta.
3. Peça: "Leia AGENTS.md, CODEX_HANDOFF.md, HISTORICO_CONVERSA.md e README.md. Audite o estado do Fluxo RIP, execute testes, priorize correções, e só depois implemente novas funções. Não envie comandos às Hoson."
4. Se o desktop oferecer **Nova conversa > abrir conversa existente do ChatGPT e adicionar ao Codex**, também selecione a conversa original para preservar mensagens e anexos no contexto do chat.

## Avisos
- Este pacote é um **handoff detalhado**, não uma cópia byte a byte de toda a conversa.
- `FluxoRIP.exe` não está pré-compilado: gerar no Windows pelo script/Actions.
- Faça backup da pasta `%LOCALAPPDATA%\FORGE` antes de atualizar o aplicativo real.
- Não incorporar senhas de manutenção PrintExp; todos os comandos reais devem continuar desativados enquanto não houver interface documentada.
